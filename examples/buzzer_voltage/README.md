# 蜂鸣器电压测量示例

这是一个独立的硬件诊断工程，用来让 P1.4 按“开启约 5 秒、关闭约 5 秒”循环，方便万用表测量蜂鸣器和驱动电路。

## 编译

从仓库根目录运行：

```sh
pio run -d examples/buzzer_voltage
```

也可以在 VS Code / PlatformIO 中单独打开本目录。主控为 STC89C52RC，晶振为 12 MHz，定时器按 12T 使用。

## 烧录和使用

正式项目与本示例各自有自己的 platformio.ini。编译本示例生成的固件位于本目录的 .pio/build/STC89C52RC/firmware.hex。

示例没有复用正式工程的自定义上传命令。若使用 stcgal，可在终端进入本目录，指定实际串口后执行：

```sh
stcgal -P stc89 -p <实际串口名> -b 9600 .pio/build/STC89C52RC/firmware.hex
```

等待工具提示后给板子断电重上电。两端接线、供电和芯片配置应与正式工程一致。

烧录后，数码管保持关闭，仅循环控制蜂鸣器。测量结束后需要重新烧录仓库根目录编译出的正式固件，才会恢复计时、计分和 OLED 显示。

该示例用于实物测量，不是自动化单元测试。等待时间包含循环开销，适合提供较长的测量窗口，不用于校准精密时基。
